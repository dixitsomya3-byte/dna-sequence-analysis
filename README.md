# DNA Sequence Analysis

## About This Project

This is a beginner-friendly bioinformatics project for analyzing DNA sequences using Python.

## Goals

- Calculate DNA sequence length
- Count nucleotides (A, T, G, C)
- Calculate GC content
- Find the reverse complement of a DNA sequence

## Tools Used

- Python
- Basic bioinformatics concepts

## Learning Objectives

This project is being developed to learn Python programming and apply it to biological sequence analysis.
